# Connect the Stack You Already Run

The Grid worker is a sidecar. Keep your existing runtime and model files, then
choose exactly which compatible capacity the worker may expose.

<Callout type="warning">
  "Available capacity" currently means the schedule and concurrency you
  configure. Automatic detection of unrelated local workload is not a general
  worker feature yet.
</Callout>
