# Connect Ollama

Ollama is the shortest path for an operator who already runs a local model. The
text worker detects the standard loopback API, lists its models, and lets you
choose one explicitly.

## 1. Verify Ollama

Start Ollama and confirm the intended model is installed:

```bash
ollama list
```

The standard endpoint is `http://127.0.0.1:11434`. The worker probes
`/api/tags`; it does not infer availability from a model directory.

## 2. Open the Worker

Download the verified text worker from
[aipowergrid.io/run](https://aipowergrid.io/run), start it using the exact
platform instructions, and open its token-protected local wizard.

1. Select the detected **Ollama** backend.
2. Select the exact model Ollama reports.
3. Run the local backend test.
4. Review context, output, schedule, and concurrency limits.
5. Approve the worker-scoped connection in Console.
6. Start the worker and wait for **Online**.

## 3. Verify Publicly

Enter the exact worker name or ID in the public check on
[the worker page](https://aipowergrid.io/run). A process that merely started is
not proof that Core accepted its registration.

<Callout type="warning">
  Grid jobs share the Ollama service with your local applications. The worker
  honors its own schedule and concurrency, but it does not generally detect and
  yield to every unrelated local request automatically.
</Callout>

Model files remain in Ollama. Community workers receive plaintext prompts and
outputs, and the Grid worker never needs a wallet private key.
