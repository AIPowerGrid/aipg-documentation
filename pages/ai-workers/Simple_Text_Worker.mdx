# Simple Text Worker

<Callout type="warning">
  This legacy worker has been retired. Do not install it or follow archived

</Callout>

The current text worker runs beside an existing Ollama, vLLM, SGLang,
LMDeploy, LM Studio, KoboldCpp, or OpenAI-compatible backend. It uses the
outbound Grid worker connection, explicit capacity controls, and verified
release artifacts.

- [Start with the verified worker download](https://aipowergrid.io/run)
- [Read the current text-worker guide](/worker-llm)
- [Connect an existing AI stack](/connect-existing-stack)
- [Choose a backend-specific quickstart](/backends)

The current worker never asks for a wallet private key. Console owns account
authentication, worker enrollment, and payout-wallet management.
