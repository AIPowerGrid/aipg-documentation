# AI Power Grid

**One API for open text, image, video, and audio models, powered by community
GPUs and settled on Base.** Build agents, generate media, and ship products
without tying your application to one closed model provider.

<Callout type="info">
  [Create an account and API key](https://console.aipowergrid.io) to start
  building. Funding, allowances, prices, and charging availability are reported
  by the Console and API; controlled rollout stages may differ by account or model.
</Callout>

---

## How It Works

Applications submit work through one API. Grid Core dispatches it to a compatible
worker, records completed work, and pays the current worker reward budget in AIPG
through verifiable transfers on Base.

```
   Apps and agents  ─requests→  Grid Core  ─dispatches→  GPU workers
          │                       │                         │
   Service credits       Metering and routing       Text and media
                                  │
                         AIPG payouts on Base
```

| Role | What you do | What you get |
|------|-------------|--------------|
| **API user** | Create a key and submit supported workloads | One account for text and media usage |
| **Funded user** | Add nontransferable service credits | Usage charged at the current published quote when charging applies |
| **Node operator** | Run a GPU worker | Earn a share of the current AIPG worker budget |
| **Validator** _(preview)_ | Submit assignment-bound evidence | Help test and secure the protocol; no rewards yet |

## Why AIPG?

- **Multimodal.** Use open text, image, video, and audio models through one Grid account.
- **Familiar APIs.** OpenAI-compatible text endpoints plus native media generation routes.
- **Community compute.** Independent GPU operators can join the network and earn from the current worker budget.
- **Verifiable payouts.** Completed worker payouts are public ERC-20 transfers on Base.
- **Honest decentralization roadmap.** Validator evidence is live in preview; rewards, penalties, and federated Core operation remain gated future work.
