## Token Utility

AIPG is the native token of The Grid. It has three core uses:

### 1. Worker Rewards

GPU operators currently receive AIPG from an hourly budget distributed pro-rata
to recorded den work units. A future multi-asset rail targets USD-valued worker
payouts, but it is not the live settlement path. Worker share scales with:
- Model size (bigger models = more AIPG per job)
- Output tokens generated
- Context length processed
- Uptime and reliability

### 2. Staking (Ended Program)

The [StakingVault](/staking) rewards program has ended — new stakes are
disabled and rewards no longer accrue. Existing stakers can withdraw anytime with
no lockup. AIPG rewards are shifting to active network participants (workers)
rather than passive holders.

**StakingVault:** [`0x3ED14A6D5A48614D77f313389611410d38fd8277`](https://basescan.org/address/0x3ED14A6D5A48614D77f313389611410d38fd8277)

### 3. Worker Bonding

Workers can optionally bond AIPG for:
- Higher priority job routing
- Increased trust score on the network
- Access to premium job tiers (future)

Bonding is not required to earn — it's a signal of commitment.

## Customer Credits and Worker Den

The Grid has two separate off-chain accounting concepts:

| Property | Value |
|----------|-------|
| | Customer account credits | Worker den |
|---|---|---|
| **Purpose** | Meter and reserve generation usage | Measure completed worker contribution |
| **Unit** | Integer micro-USD, displayed in USD | Internal work units |
| **Changes through** | Idempotent grants, deposits, reservations, settlement, and refunds | Accepted completed jobs |
| **Transferable** | No | No |
| **Economic role** | Spendable only as reported by `/v1/account/credits` | Determines pro-rata payout-period share; not a fixed exchange promise |

Worker den is **not** AIPG and must not be shown as a customer's balance.

## History

AIPG originally launched as a Ravencoin fork with Proof of Work mining and a halvening emission schedule. The project has since migrated to **Base L2** with all 150M tokens minted as a fixed-supply ERC-20. The original PoW chain is no longer active.

For the original whitepaper describing the PoW era, see [Whitepaper](/whitepaper).
